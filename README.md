# MVP консультанта по сетевому оборудованию

Агент использует базу знаний для инструкций и правил, SQLite-каталог для цен,
остатков и характеристик товаров и долговременную память пользователя.

## Подготовка среды

Требуются [Homebrew](https://brew.sh/) и [`just`](https://just.systems/).

```bash
just setup
just python 3.14.5
just lock && just install
```

Команды устанавливают `pyenv` и `uv`, устанавливают Python 3.14.5, создают `.venv` и устанавливают зависимости.

## Подготовка данных

```bash
just prepare
```

`prepare` запускает `catalog_restore` для восстановления SQLite-каталога из
CSV-слепка и `rag_rebuild` для полной пересборки vector store.

## Запуск

```bash
just run_agent
```

Агент использует заранее подготовленные данные и не изменяет их при запуске.

## Проверки

```bash
just lint
just test
```

`just test` самостоятельно восстанавливает каталог и пересобирает vector store,
после чего выполняет unit- и smoke-тесты.

Полный сброс локальных runtime-данных:

```bash
just clear_runtime
```

Команда очищает память и удаляет сгенерированные каталог и RAG-данные. Исходные
CSV и документы остаются без изменений. После сброса снова выполните
`just prepare`.
