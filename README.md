# ИИ-агент поддержки инженера

## Подготовка среды

Требуются [Homebrew](https://brew.sh/) и [`just`](https://just.systems/).

```bash
just setup
just python 3.14.5
just lock && just install
```

Команды устанавливают `pyenv` и `uv`, устанавливают Python 3.14.5, создают `.venv` и устанавливают зависимости.

## Запуск

```bash
just run
```

Проверки:

```bash
just lint
just test
```
